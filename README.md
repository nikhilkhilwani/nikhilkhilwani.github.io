# nikhilkhilwani.github.io

Personal portfolio site. Currently a **coming soon** landing page.

## Files

- `index.html` — the landing page (single file, no build step)
- `favicon.svg` — tab icon
- `.nojekyll` — tells GitHub Pages to serve files as-is

## Preview locally

```sh
python -m http.server 8000
# then open http://localhost:8000
```

## Publish

1. Create a GitHub repo named exactly `nikhilkhilwani.github.io`.
2. Push this folder to the default branch.
3. Settings → Pages → Source: *Deploy from a branch* → branch `main`, folder `/ (root)`.
4. Live at https://nikhilkhilwani.github.io within a minute or two.

## Before going live

Update the placeholders in `index.html`:

- `mailto:hello@example.com` → your real email
- GitHub / LinkedIn URLs → your real profiles
